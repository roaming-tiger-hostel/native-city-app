# Native City 기능설명서 (1차 기능심사 초안)

> 노션 제공 공식 양식이 있으면 **그 양식에 내용을 옮겨 적고**, 이 문서는 내용 초안이다. PDF 변환·용량 제한은 제출 폼 안내에 따른다.

## 1. 서비스 한 줄
서울 방문 여행자가 문화·식사 제약·취향에 맞는 AI 친구와 대화하며, 한국관광공사 TourAPI 장소를 근거로 추천받는 웹 서비스.

## 2. 주요 기능
1. 게스트 `/guest`: 캐릭터 선택 → 옵션/자유 채팅 → 추천 장소 카드 → 지도·출처
2. 턴마다 제타형 **미리 정해진 답 칩(replyChips)** (탭하면 전송)
3. 문화·여행 프리셋(할랄·채식·예산·K-pop·한식입문·조용한골목 등)과 기본 친구 세트
4. 호스트 `/studio`: 취향 A/B·장소 동기화(TourAPI)로 추천 조정
5. 심사 안내 `/submit`: TourAPI·LLM 설정 상태 확인

## 3. 테스트 URL (공개)
| 용도 | URL |
| --- | --- |
| 게스트 | https://native-city.vercel.app/guest |
| 호스트 | https://native-city.vercel.app/studio |
| 심사/설명 | https://native-city.vercel.app/submit |

테스트 계정: **필수 아님** (위 URL 직접 접속). 데모 `/login`이 있으면 guest/guest2026, trainer/trainer2026 (실제 인증 아님).

## 4. 한 바퀴 시나리오 (~3분)
1. `/guest` → 프리셋/친구 선택 → 자유 입력 또는 답 칩 탭 → 캐릭터 응답 확인
2. “밤 11시, 돼지고기 없는 야식” 등 → 장소 옵션 선택 → 지도·주소·출처(TourAPI) 확인
3. `/studio`에서 취향 더하기 후 `/guest` 추천 변화 확인(항상 1순위 뒤집히는 것은 아님)
4. `/submit`에서 TourAPI/LLM 상태 확인

## 5. 한국관광공사 OpenAPI 활용
서비스명(포털): 국문 관광정보서비스_GW (KorService2 등)

| API | 앱 위치 | 쓰는 정보 |
| --- | --- | --- |
| locationBasedList2 (Kor/Eng) | `/api/tour`, `/api/chat`, 스튜디오·지도 | 호스텔 인근 음식점·관광지 명칭/주소/좌표/이미지 |
| searchKeyword2 | 스튜디오 검색·채팅 장소 요청 | 검색 후보 |
| detailCommon2 | `/api/tour?contentId=` | 개요·연락처·좌표 |

실시간 호출 실패 시 데모 시드 폴백이 있으며, 시드만으로는 공사 호출 성공 증빙이 아님. 할랄 인증·실시간 영업 여부는 미제공.

## 6. 차별점·발전
- 불특정 리뷰가 아니라 **누구의 취향으로 추천받느냐**(네이티브/호스트 귀속 추천)
- 단기: 답 품질·호스트 학습 루프·TourAPI 근거 강화
- 중기: 커머스/투어 대행 수수료, 더 많은 문화권 친구

## 7. 현재 제약 (정직하게)
- 프로덕션 LLM 키 없으면 규칙 엔진/폴백 칩으로 동작 가능
- 영구 DB·실인증·요청량 제한은 데모 단계
- 민감 개인정보 입력 금지
