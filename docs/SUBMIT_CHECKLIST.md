## 기능설명서에 넣을 서비스 개요

서울을 방문한 여행자가 문화·식사 제약·여행 취향에 맞는 AI 친구와 대화하며 장소를 고르는 웹 서비스. 기본 8명은 스튜디오 훈련 없이 대화를 시작하며, 한국어/영어와 옵션 채팅/자유 입력을 지원한다. 호스트의 A/B 선택은 선택적으로 추천 순위를 조정한다. 캐릭터 설정과 손님 선호는 예시 데이터이며 실제 인물 복제나 검증된 방문 경험이 아니다.

## TourAPI는 어디에 쓰는가

| API | 앱 진입점/화면 | 활용하는 사실 정보 |
| --- | --- | --- |
| KorService2/locationBasedList2 | `/api/tour`, `/api/chat`, 스튜디오 동기화, 지도 | 호스텔 좌표 반경 4km, 음식점 39·관광지 12의 명칭/주소/좌표/이미지 등 |
| EngService2/locationBasedList2 | 초기 카탈로그 보강 | contentId가 같은 장소의 영문명·주소·개요 병합 |
| JpnService2/locationBasedList2 | 카탈로그 로딩의 호출 점검 | 호출 성공 여부 기록. 일본어 표시/대화는 아직 구현 범위 밖 |
| KorService2/EngService2/searchKeyword2 | 스튜디오 키워드 검색, 채팅의 장소 요청 | 검색 후보 확장. 식이 필터와 캐릭터 추천 범위는 그대로 적용 |
| KorService2/detailCommon2 | `/api/tour?contentId=...` 상세 조회 | 공사에서 제공한 개요·연락처·좌표 등. contentId 없는 데모 장소는 호출 불가 |

코드 근거: `src/lib/tourapi.ts`, `src/lib/engine.ts`, `src/app/api/tour/route.ts`, `src/app/api/chat/route.ts`.

현재 앱의 카드·상세가 모두 detailCommon2를 자동 호출하는 것은 아니다. 상세 엔드포인트는 위 URL로 직접 검증 가능하다. live 호출과 seed 모드를 구분하며, 시드 배지 자체는 이번 배포의 공사 호출 성공 증빙이 아니다. 할랄 인증·현재 영업·폐점 확인 기능은 없다. 식이 제약이 확인되지 않은 장소는 식사 후보에서 제외한다.

## 테스트 계정

**필수 아님.** `/guest`, `/studio`, `/submit`에 직접 접속할 수 있다.

기존 `/login` 데모 체험을 따로 확인할 경우:

| 역할 | ID | 데모 비밀번호 |
| --- | --- | --- |
| 손님 | guest | guest2026 |
| 트레이너 | trainer | trainer2026 |

이 로그인은 실제 인증·권한 통제가 아니다. 심사 시 실제 개인정보를 넣지 않는다.

## 기능설명서용 한 바퀴 시나리오 (약 3분)

1. `/guest`에서 K-pop 프리셋 → 하나 → “요즘 어떤 음악 좋아해?” 자유 입력. “그냥 수다 떨자” 버튼도 눌러 장소 추천 없는 캐릭터 대화를 확인한다. Qwen 미설정 시 준비된 엔진 답변임을 설명한다.
2. 마야 → “밤 11시, 돼지고기 없는 야식” → 캐릭터 응답과 추천 옵션 확인 → 장소 하나 선택 → 지도/주소/출처 확인. 돼지고기 제외는 할랄 인증이 아님을 안내한다.
3. 리나의 “채식 점심 추천해 줘”, 톰의 예산 취향, 달의 조용한 골목 취향을 비교한다. EN으로 바꿔 영문 대화도 확인한다.
4. `/studio`에서 마야 선택 → 취향 더하기 → 이유 입력 → 두 장소 중 하나 선택. `/guest`에서 다시 추천해 순위 반영을 확인한다. 모든 판정이 반드시 1순위를 뒤집는 것은 아니다.
5. 스튜디오 장소 탭 → TourAPI 동기화 또는 키워드 검색 → 상세 보기 → 실제 호출 로그 확인. `/submit`에서 현재 TourAPI 및 Qwen 설정 상태를 확인한다.

## 현재 제한 / 남은 운영 작업

- Vercel에서 맥미니 localhost 접근 불가. 배포 생성형 대화에는 별도 DashScope 키 필요.
- 키 없음/서버 장애/응답 검증 실패는 규칙 엔진으로 폴백. 엔진 잡담은 고정된 짧은 응답.
- 프롬프트와 출력 검사로 환각을 줄이지만 알려지지 않은 모든 장소명을 완벽히 판별하지는 못함.
- 브라우저 localStorage·로컬 파일·Vercel `/tmp` 기반. 기기 간 동기화/영구 DB 없음.
- 실제 인증·권한 통제·요청량 제한은 운영 전 추가 필요. 공개 데모에 민감정보 금지.
- 신규 두 친구 아바타는 SVG 일러스트. 기존 여섯 명의 포트레이트와 매체 스타일이 다름.
- 이 작업 환경에서 localhost 연결·포트 바인딩·Git 쓰기가 제한되면 실모델/브라우저/푸시 검증 결과를 별도 기록하고, 완료로 표시하지 않음.
